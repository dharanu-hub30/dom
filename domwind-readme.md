# WindWave DOM Lab

Practicum site on the usage of DOM elements for user interactions, themed on wind energy for smart cities.

## Files
- `domwind-page.html` – the page
- `domwind-style.css` – styles and animations
- `domwind-script.js` – form validation, dropdown toggle, modal, DOM activity log
- `vercel.json` – opens the page at the site root (keep this exact name)

## Upload to GitHub
1. Create a NEW repository for this site.
2. Add file -> Upload files, drag in the unzipped files (not the zip), and commit.

## Deploy on Vercel
1. Vercel -> Add New -> Project, import the repository.
2. Framework Preset: Other. Leave build settings empty. Deploy.

Note: the first practicum site also has a `vercel.json`. Keep the two sites in separate repositories.
